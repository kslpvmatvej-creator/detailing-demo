# PRIME DETAILING • DEMO

Демо онлайн-записи для детейлинг-студий. На одном сайте можно мгновенно переключаться между тарифами:

- **LITE** — простая заявка в 2 шага (услуга со скидкой → контакты + «Откуда узнали»);
- **PRO** — умная запись: класс авто → услуга с чек-листом → дата и свободный слот с учётом боксов → допродажи → контакты.

Весь бэкенд отключён: нет Supabase, нет отправки в Telegram. Занятость боксов генерируется на фронтенде,
заявка «отправляется» с задержкой 400 мс, а на экране успеха показывается превью Telegram-уведомления
с данными, которые посетитель только что ввёл. Демо невозможно заспамить.

## Запуск

```bash
npm ci
npm run dev      # локально
npm run build    # сборка в dist/
```

## Деплой на GitHub Pages

1. Залейте проект в репозиторий (ветка `main`).
2. Settings → Pages → Source: **GitHub Actions**.
3. Каждый push запускает `.github/workflows/deploy.yml`.

Базовый путь относительный (`./`), поэтому сайт работает и на `user.github.io/<repo>/`, и на своём домене.

## Что где

| Файл | Назначение |
| --- | --- |
| `src/business.json` | бренд, контакты, боксы, допы, часы работы |
| `src/lite/lite.json` | услуги LITE, источники «Откуда узнали», скидка |
| `src/lib/slots.ts` | услуги PRO: цены, длительность, чек-листы |
| `src/lib/busy.ts` | генератор занятости боксов (демо) |
| `src/lib/telegram.ts` | шаблоны Telegram-сообщений LITE / PRO |
| `src/components/BookingModal.tsx` | окно записи и переключатель LITE / PRO |
